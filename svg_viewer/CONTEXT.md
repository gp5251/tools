# SVG Viewer

一款系统文件查看器：以画廊形式浏览某个文件夹中的 SVG 集合。目标用户是普通用户与设计师，典型使用规模为一个文件夹内含几百张 SVG。

## Language

**Library（图库）**:
用户指定的一个文件夹**当前层**中全部 SVG 文件的集合，是浏览的基本单位。不含子目录；换一个文件夹就是换一个 Library。典型规模为几百张。
_Avoid_: 相册、项目、工作区

**Gallery（画廊）**:
以网格形式陈列 Library 中所有 SVG 的主视图。单一可滚动视图，无分页；动画 SVG 在此冻结为静态快照。
_Avoid_: 列表、瀑布流、缩略图墙

**Viewer（单图视图）**:
一次显示一张 SVG 大图的视图，用于凑近检查单张图。双击 .svg 文件的默认落点，与 Gallery 可一键互相切换。能力刻意收敛：棋盘格背景 + 滚轮缩放，无翻页无平移。
_Avoid_: 详情页、阅读模式

**Hover Preview（悬停预览）**:
鼠标悬停在 Gallery 中某张图上时出现的放大预览，跟随鼠标移动。动画 SVG 在此处播放。
_Avoid_: 弹窗、灯箱（lightbox）
