# 09 — 画廊缩略图大小可调（四档位）

**What to build:** 画廊缩略图支持四档大小：50 / 100 / 150 / 200px，默认 200px（当前样子）。两种调整方式：画廊内 Ctrl + 滚轮（向上升档、向下降档，两端钳制），以及工具栏的档位按钮（当前档高亮）。调整后的档位写入 localStorage，下次启动恢复；持久化失败静默降级为默认值。快照光栅化分辨率保持 200px 不变，纯显示层缩放（canvas 拉伸），不重新栅格化。

**Blocked by:** None（Gallery 渲染通路已就绪，纯显示层改动）
