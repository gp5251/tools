# 03 — Hover Preview

**What to build:** 鼠标悬停在 Gallery 中某张图上时，出现一个跟随鼠标移动的放大预览（Hover Preview）。与画廊的静态快照不同，预览里是活 SVG——带动画的 SVG 在此播放。鼠标移开预览即消失。同一时刻最多只有一个活预览在渲染。

**Blocked by:** 02 — Gallery：静态快照网格

**Status:** done

- [ ] hover 画廊项出现放大预览，位置跟随鼠标
- [ ] 预览中动画 SVG 正常播放
- [ ] 移开鼠标预览消失，不残留
- [ ] 快速扫过多张图时不会同时出现多个预览
