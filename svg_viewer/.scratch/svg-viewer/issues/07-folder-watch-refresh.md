# 07 — 文件夹监听自动刷新

**What to build:** 应用打开期间监听 Library 文件夹：外部新增、删除、修改 SVG 时，画廊自动反映变化（设计师从 Figma/Illustrator 导出新图进来要自动出现）。监听必须容忍应用自身的重命名/删除操作，不出现抖动或重复刷新；文件在渲染过程中被外部删除等竞态要安全降级（显示占位卡或直接消失，不崩溃）。

**Blocked by:** 02 — Gallery：静态快照网格

**Status:** done

- [ ] 外部新增 SVG 自动出现在画廊正确排序位置
- [ ] 外部删除/修改 SVG 自动从画廊移除或更新
- [ ] 应用内重命名/删除不触发抖动或重复刷新
- [ ] 渲染过程中文件被外部删除时安全降级，不崩溃
